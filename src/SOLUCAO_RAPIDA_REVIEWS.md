# ?? Solução Simplificada - Reviews Table Fix

## ? Solução Rápida (SEM PSQL)

Como você não tem o `psql` instalado e há problemas de autenticação NuGet, use esta abordagem:

### Opção 1: Usar pgAdmin ou DBeaver (RECOMENDADO)

1. Abra seu cliente PostgreSQL (pgAdmin, DBeaver, ou outro)
2. Conecte ao banco de dados `mychurch_db`
3. Execute o seguinte SQL:

```sql
DO $$
BEGIN
    IF NOT EXISTS (
        SELECT FROM information_schema.tables 
        WHERE table_schema = 'public' 
        AND table_name = 'Reviews'
    ) THEN
        CREATE TABLE "Reviews" (
            "Id" integer NOT NULL GENERATED BY DEFAULT AS IDENTITY,
            "EntityId" integer NOT NULL,
            "EntityType" character varying(50) NOT NULL,
            "ReviewerId" integer NOT NULL,
            "Score" integer NOT NULL,
            "Comment" character varying(1000) NOT NULL,
            "CreatedAt" timestamp without time zone NOT NULL,
            "IsVerified" boolean NOT NULL DEFAULT false,
            "WorshipPresenceId" integer NULL,
            "VerifiedAt" timestamp without time zone NULL,
            CONSTRAINT "PK_Reviews" PRIMARY KEY ("Id"),
            CONSTRAINT "FK_Reviews_member_ReviewerId" FOREIGN KEY ("ReviewerId") 
                REFERENCES postgres.member(id) ON DELETE RESTRICT,
            CONSTRAINT "FK_Reviews_worship_presences_WorshipPresenceId" FOREIGN KEY ("WorshipPresenceId") 
                REFERENCES postgres.worship_presences(id) ON DELETE SET NULL
        );

        CREATE INDEX "IX_Reviews_ReviewerId" ON "Reviews" ("ReviewerId");
        CREATE INDEX "IX_Reviews_WorshipPresenceId" ON "Reviews" ("WorshipPresenceId");
        
        RAISE NOTICE 'Tabela Reviews criada com sucesso!';
    ELSE
        RAISE NOTICE 'Tabela Reviews já existe.';
    END IF;
END
$$;
```

4. Depois adicione o registro da migration no histórico:

```sql
-- Adicionar a migration ao histórico do EF Core
INSERT INTO postgres.__efmigrationshistory (migration_id, product_version)
VALUES ('20251215000000_FixMissingReviewsTable', '9.0.3')
ON CONFLICT DO NOTHING;
```


## ? Verificação

Após executar o SQL, verifique:

```sql
-- Ver se a tabela foi criada
SELECT table_name FROM information_schema.tables 
WHERE table_name = 'Reviews';

-- Ver estrutura
\d "Reviews"

-- Ver migrations aplicadas
SELECT * FROM postgres.__efmigrationshistory 
ORDER BY migration_id DESC 
LIMIT 10;
```

## ?? Depois da Correção

Uma vez que a tabela esteja criada:

1. **Resolver problema do NuGet** (se necessário):
